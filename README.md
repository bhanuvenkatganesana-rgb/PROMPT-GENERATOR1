
# PromptGenius: AI Prompt Generator

**PromptGenius** is a Streamlit-powered web application that leverages the **NVIDIA NIM Inference Engine** and **DeepSeek V4.1 Flash** model to convert casual user prompts into structured, production-ready AI prompt frameworks.

---

## Overview

Writing effective prompts for LLMs requires clear structure, specific roles, strict constraints, and formatted outputs. PromptGenius automates this engineering process by taking informal instructions and automatically structuring them into a **5-Part Prompt Framework**:

1. **Who Are You:** Defines the persona, domain expertise, and core responsibilities.
2. **Prerequisites Required:** Details necessary context, codebases, toolings, and constraints.
3. **What You Should Do:** Outlines sequential tasks, explicit requirements, and target outcomes.
4. **What Not To Do:** Specifies critical boundary conditions and guardrails to prevent hallucination or unnecessary changes.
5. **How Your Reply Should Be:** Formats the required delivery style and final reporting requirements.
